# 🎵 Music Label Management System (Java + MySQL using JDBC)

This project is a **mini DBMS application** developed as part of my **Undergraduate coursework**. It demonstrates how Java can interact with a MySQL database using **JDBC** to simulate a basic **Music Label Management System**.
The application runs entirely through a **User Console Interface**, focusing on core database operations rather than UI design.

---

## 📌 Project Overview

The system manages essential components of a music label, including:

* **Artists** – information about musicians associated with the label
* **Albums** – album details linked with respective artists
* **Tracks** – song-level data for each album
* **Events** – performances or promotional events involving artists
* **Royalties** – payment and earning records for artists and tracks

The project demonstrates CRUD operations, SQL queries, relational integrity, and console-based navigation using Java.

---

## 🛠️ Technologies Used

* **Java** (Core Java + JDBC)
* **MySQL** (Database)
* **JDBC Driver** for MySQL
* **Console-based UI**

---

## 📂 Features

* Add, view, update, and delete **artists**, **albums**, **tracks**, **events**, and **royalty records**
* Proper relational mapping between database tables
* Console-based menu-driven interface
* Clean backend architecture with database connectivity using JDBC
* Demonstrates DBMS concepts like:

  * Primary/foreign keys
  * Joins
  * Data consistency
  * Transaction-like operations (where applicable)

---

## 🧱 Database Schema (Summary)

The database contains the following tables:

* **artists**
* **albums**
* **tracks**
* **events**
* **royalties**

These tables are interlinked to reflect real-world relationships inside a music label.

## ▶️ How to Run

1. Install **Java** and **MySQL Server**
2. Import the SQL file (if provided) or manually create tables
3. Update database credentials in the Java code
4. Add the MySQL JDBC Driver to the project
5. Run the program through your Java IDE or command line
6. Navigate using the **console menu**
